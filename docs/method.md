# 方法说明

## 先确定评估边界

记录评估对象、评估时点、观察期、材料范围与采用的规则版本。先给事实编号，再判档；不要为了匹配预期总分反向调整输入。

## 输入与致命层

六项档位组成向量 `r`，每项属于 `{0,25,50,75,95}`。作用链必须有起点、终点、放大关系的证据和去重记录；每条 5 分，最多 15 分，记作 `C`。`C>0` 要求至少两个系统有非零风险。

致命条件使用“成立 / 不成立 / 未知”三种状态。以现金为例，需要核对必要付款存在、可用资金不足、经营因此不能继续、期限内没有已落实补救等事实。具体业务应在评估前登记自己的条件；计算器接收最终判定，不自动推断。

- “且”：有一项不成立就不成立；全部成立才成立；其余未知。
- “或”：有一项成立就成立；全部不成立才不成立；其余未知。

致命已成立时直接输出 100。尚未知时输出待补证；只有致命已排除，才进入非致命合成。这里的三值是逻辑值，不是概率。

## 非致命合成

令 `M=max(r)`，`S=sum(r)-M`。最大值并列时，只减去一项；定义不依赖选择哪一项。

### A：允许叠加升档

```text
g_A = min(99, M + 0.1*S + C)
```

A 保留最高单项下界，并允许其他系统推高总分；但不保证最高单项更严重的状态总排在前面。例如六项均为 75、C=0 时得到 99，一项为 95、其余为 0 时得到 95。

### B：最高档优先（当前推荐）

| 最高档 M | 非致命分数区间 |
| --- | --- |
| 0 | 0 |
| 25 | 25–49 |
| 50 | 50–74 |
| 75 | 75–94 |
| 95 | 95–99 |

全部为零时 `g_B=0`；否则取上表对应上界 `u`：

```text
T = 0.1*S + C
Z = 0.5*M + 15
g_B = M + (u-M)*T/Z
```

因其余五项都不超过 M，所以 `0<=T<=Z`。B 把叠加限制在当前档内，以此保留最高档优先。1–24 在该规则中不使用；100 专属已核实致命状态。

两种方案的显示分均为 `floor(g+0.5)`，即 0.5 向上进位。代码使用有理数计算，避免二进制小数改变进位结果。

## 缺失信息

未知不填零。致命条件已排除、且已有事实复核完成时，枚举与证据一致的可行补全，将最小和最大结果一起输出。即使端点相同，也保留“资料不全”的状态。

计算器中档位 `None` / 命令行 `?` 覆盖五个档位；作用链 `None` 覆盖四个加分。已有证据若限制了未知范围，应进一步收窄可行补全集合；当前命令行只提供完整未知或精确已知两种输入。

## 输出应包含什么

方案与版本、致命状态、六项档位、作用链及证据、原始分或区间、整数显示和未解决材料。总分相同不表示问题结构相同。

## 这套规则能检验什么

枚举能检查指定形式域内的下界、封顶、单项保真、单调性与排序关系。它不能证明材料真实、分档可靠、参数最优，或指数能预测未来经营结果。系数 0.1、每链 5 分和判据中的时间阈值都是待检验的规范参数。
