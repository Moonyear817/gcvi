# 六个系统的分档判据

从原操作说明的判据整理。每档都要记录事实、时点、期限和补救资源；以下阈值是试行约定。未来 30 天与未来 7 天等时间口径应在评估前固定，不能根据算出的分数事后调整。未知单独记录，不能套用 0 档。

## 现金

| 档位 | 判据 |
| --- | --- |
| 0 | 未来30天的必要付款都有核对过的可用资金或确定到账覆盖，没有已知的逾期缺口。 |
| 25 | 总体能覆盖，但付款或到账比较集中；已落实的安排能在期限内解决局部波动。 |
| 50 | 覆盖部分依赖还没落实的到账或延期，资金预测有不确定性，还没有确认必要缺口。 |
| 75 | 已经确认未来某笔必要付款有缺口，还没有发生致命中断，补救没有落实。 |
| 95 | 最晚付款期限在未来7天内，缺口已确认，维持经营依赖还没落实的关键资金或延期。 |

## 业务与收入

| 档位 | 判据 |
| --- | --- |
| 0 | 观察期的真实收款和单位经济可以核对，必要业务和经营成本有可持续的支撑。 |
| 25 | 局部波动或成本问题有已落实的处理，必要业务继续运转。 |
| 50 | 需求或成本问题反复出现，经营依赖临时补贴、一次性订单等，持续支撑还没有验证。 |
| 75 | 必要业务的收入明显无法覆盖持续支出，支撑资源继续消耗，替代或收缩方案没有落实。 |
| 95 | 支撑资源接近耗尽，必要业务接近中断，继续经营依赖还没落实的关键订单或转型。 |

## 交付

| 档位 | 判据 |
| --- | --- |
| 0 | 已承诺的交付都有明确负责人、资源和完成依据，没有未修复的重大交付问题。 |
| 25 | 局部异常已经由明确的替代或修复安排解决，必要订单仍可完成。 |
| 50 | 至少两件同类问题没有修复，交付部分依赖临时协调，还没有阻断必要交付。 |
| 75 | 必要交付明显受损，已有订单的资源或人员缺口没有落实修复。 |
| 95 | 最晚交付期限在未来7天内，必要资源仍然缺失，完成订单依赖还没落实的关键替代。 |

## 团队

| 档位 | 判据 |
| --- | --- |
| 0 | 必要岗位有人承担，投入时间与任务匹配，关键岗位有可用的交接或替代安排。 |
| 25 | 局部缺勤或投入波动有落实的替代，必要岗位仍能履责。 |
| 50 | 反复缺位或长期依赖一个人救场，必要岗位的稳定投入还没有落实。 |
| 75 | 关键岗位投入已经明显不足或确认要退出，必要任务受损，替代没有落实。 |
| 95 | 关键岗位将在未来7天内无人可用，必要经营接近中断，没有落实的替代。 |

## 治理

| 档位 | 判据 |
| --- | --- |
| 0 | 必要决策、资源调用和执行责任明确，近期的决定能形成执行和核对结果。 |
| 25 | 局部职责或授权不清，已落实协调安排，必要的决定能执行。 |
| 50 | 决策或责任问题反复出现，部分依赖临时协调，近期仍可完成必要决策。 |
| 75 | 必要决策或资源调用明显受阻，必要任务受损，授权和执行安排没有落实。 |
| 95 | 必要决定的最晚执行期限在未来7天内，仍然无法有效决策或调用资源，经营接近中断。 |

## 必要经营条件

| 档位 | 判据 |
| --- | --- |
| 0 | 已识别本业务的必要条件并核对了有效性；业务不需要的资格不列为缺口。 |
| 25 | 某个条件即将变化，续期、替代或修复已经落实，并且赶得上期限。 |
| 50 | 某个条件存在已知的不确定性，还没有形成明确的中断安排，补充核对正在进行。 |
| 75 | 已经确认某个必要条件将失效或严重受限，期限前的恢复或替代没有落实。 |
| 95 | 某个必要条件将在未来7天内失效，没有落实的替代，经营接近中断。 |
