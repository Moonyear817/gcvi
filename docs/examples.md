# 模拟算例

以下输入是用于复算的构造向量，不对应具体组织。除特别说明外，均假定致命条件已核实不成立、材料已复核。

| 档位向量 | C | A 显示分 | B 显示分 |
| --- | --- | --- | --- |
| (75,50,50,25,25,0) | 5 | 95 | 82 |
| (25,50,25,25,25,0) | 0 | 60 | 56 |
| (95,95,75,75,50,25) | 15 | 99 | 98 |
| (75,75,75,75,75,75) | 0 | 99 | 89 |
| (95,0,0,0,0,0) | 0 | 95 | 95 |

## 第一行怎样得到 82

`M=75`，`S=150`，`C=5`。B 的当前上界为 94，故：

```text
T = 0.1*150 + 5 = 20
Z = 0.5*75 + 15 = 52.5
g_B = 75 + 19*20/52.5 = 1727/21 ≈ 82.238095
显示分 = 82
```

同一组输入的 A 为 `min(99,75+15+5)=95`。差异来自排序规则，不是两套材料。

## 资料不全

输入 `(75,?,50,25,25,0)`，C 也未知且可为 0、5、10、15：B 的显示范围为 **79–97**。

如果 C 已知为 5，其他输入相同，显示范围收窄为 **80–96**。这两个范围使用不同的信息条件，不能互换。

## 致命和待补证

- 已核实致命，其他六项全部未知：100。
- 致命未知，即使六项都填 0：待补证。
- 只有一个系统非零，却声称存在作用链加分：非致命输入不可行，应回头核对材料。
- 六项皆已知，但材料未复核：待补证。

## 四舍五入

A 在六项都为 25、C=15 时，原始分为 52.5，显示 53。Python 内置 `round` 的半偶数规则与本项目不同，不能直接替代。
